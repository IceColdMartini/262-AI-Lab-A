## Problem Statements

### 1. Aliceland Relief Rover (15 Marks)
* **Objective:** Modify the provided baseline function `base_astar_search` to implement `solve_aliceland_rover(grid, start, goal)`.
* **Description:** Navigate an autonomous relief rover from a central distribution depot to a stranded aid station across a 2D integer matrix grid while avoiding impassable floodwalls (`-1`) and minimizing cumulative energy cost.

### 2. Karp City Hovercraft (15 Marks)
* **Objective:** Modify the baseline $A^*$ algorithm to implement `solve_karp_city(grid, start, goal, portals, portal_cost=1.0)`.
* **Description:** Transport vaccines across a city grid containing roadways and high-rise structures utilizing standard cardinal movements and Quantum Warp Portals to bypass urban blockades.
